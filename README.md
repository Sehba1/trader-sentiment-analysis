# Trader Behavior vs Market Sentiment

This project analyzes the relationship between Bitcoin market sentiment
(Fear & Greed Index) and trader behavior using historical trade data.

## Contents
- Google Colab / Jupyter Notebook with full analysis
- Exploratory data analysis and visualizations
- Insights on trader performance and risk behavior

## Tools Used
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
